DOMAS

Domain Oriented Mapping of Alternative Splicing — map differential splicing events onto protein domain architectures. Choose your input format, select the file(s), and press Process. The first 100 alternative splicing events are analyzed.

Help

DOMAS takes the output of a differential splicing tool and maps each alternative splicing event onto the protein domains it affects. For every event it finds the domains lying in the affected region, and classifies what the alternative transcript does to them compared with the protein encoded by the canonical transcript: a domain lost, gained, lengthened or shortened, left unchanged, or a transcript that codes for no protein at all. The result is one row per affected domain, which you can read in the table below or download as a CSV.

Input formats

Choose the tool your file came from, then select the file(s) it needs. None of these formats records which species the data came from, so choose that as well.

FormatFiles to load
LeafCutter Two files from a leafcutter_ds run: the cluster significance file (leafcutter_ds_cluster_significance.txt) and the effect sizes file (leafcutter_ds_effect_sizes.txt). Both are needed — the significance of an event is in one, the change in inclusion of each of its junctions in the other.
sample significance file · sample effect sizes file
rMATS The junction-count files from an rMATS-turbo run, selected together: SE.MATS.JC.txt, A3SS.MATS.JC.txt, A5SS.MATS.JC.txt, MXE.MATS.JC.txt and RI.MATS.JC.txt. Any subset works — only the event types you load are analyzed.
sample SE file
MAJIQ A single voila tsv file, e.g. NveB_Mono_voila.txt.
sample file
SUPPA A single events .ioe file.

Output

One row per affected domain. The rows are ordered by the effect on the domain, most consequential first: lost protein, domain gain, domain loss, longer domain, shorter domain, no domain change. The two length changes are ordered within themselves by the size of the change, largest first.

Download results gives a zip of Excel workbooks plus the run summary as a text file: compared.xlsx, one row per affected domain, and non_compared.xlsx, one row per event that reached no domain comparison, each naming why. The rows are the ones shown above, in the same order.

ColumnMeaning
event Name of the alternative splicing event, as the input file identifies it.
alternative_transcripts_group The group of alternative transcripts this row describes. Transcripts sharing the same junctions across the event form one group, and one representative of the group is compared to the canonical transcript.
gene_symbol The gene the event falls in. Links to the gene in DoChaP.
species The species chosen for the run.
event_effect_on_domain One of the following:
  • Lost protein – the alternative transcript does not code for a protein
  • Domain gain – the alternative transcript codes for a protein with an additional domain
  • Domain loss – the alternative transcript codes for a protein without this domain
  • Longer domain – the alternative transcript codes for a protein with a longer domain
  • Shorter domain – the alternative transcript codes for a protein with a shorter domain
  • No domain change – the alternative transcript codes for a protein with an unchanged domain
canonical_transcript_id Transcript ID of the canonical transcript. Mostly ENSEMBL. See paper for selection process.
alternative_transcript_id ENSEMBL/NCBI transcript ID of the alternative transcript that represents the transcripts group. See paper for selection process.
canonical_junctions Genomic coordinates of the canonical junction(s) involved.
alternative_junctions Genomic coordinates of the alternative junction(s) involved.
domain_id From Pfam.
domain_name From the DoChaP database.
canonical_domain_length Length of the domain in the protein encoded by the canonical transcript — the total if there is more than one instance.
alternative_domain_length Length of the domain in the protein encoded by the alternative transcript — the total if there is more than one instance.
length_change_pct How much the domain's length changed, as a percentage of its length in the canonical transcript: the absolute difference between the two lengths divided by the canonical one. A magnitude, so a domain cut in half and one grown by half both read 50 — the outcome column says which. Empty where the change cannot be measured: rows with no domain lengths at all (Lost protein), and any row whose canonical domain length is zero — a Domain gain where the canonical side holds no instance of the domain at all. A gain from one instance to two does have a canonical length, and so does get a percentage. The results are ordered by this number within the Longer domain and Shorter domain blocks, largest change first.
canonical_domains_number Number of instances of the domain in the affected region in the protein encoded by the canonical transcript.
alternative_domains_number Number of instances of the domain in the affected region in the protein encoded by the alternative transcript.
domain_description From the DoChaP database.

About DOMAS

Domain Oriented Mapping of Alternative Splicing (DOMAS) bridges the gap between a differential splicing event and its effect on the protein. It takes a list of differential splicing events, maps them onto protein domain architectures in a coordinate-aware way, and annotates each event with the domains it affects and the class of that effect compared with the protein encoded by the canonical transcript.

Input: the output of several differential splicing tools — LeafCutter (Li et al., 2016), rMATS-turbo (Wang et al., 2024), MAJIQ (Vaquero-Garcia et al., 2023) and SUPPA .ioe files. To ask for another input format, please write to us.

Output: a table listing the domains affected by each alternative splicing event and the class of the effect, downloadable as an Excel workbook. Each gene links to its visualization in DoChaP, showing the canonical and the compared transcript.

Protein domain annotation: DOMAS builds on the DoChaP database, which integrates domain annotation from several sources. Domains reported here come from Pfam.

This page runs DOMAS on the first 100 alternative splicing events of the file you upload. For a full dataset, DOMAS is also available as a command-line tool.

Publication: Shani T Gal-Oz, Nimrod Haiat, Dana Eliyahu, Guy Shani, Tal Shay, DoChaP: the domain change presenter, Nucleic Acids Research, 2021, gkab357.

Contact: galozs@post.bgu.ac.il
