Unpacking it

The download is a gzip-compressed tar archive holding a single file, DB_merged.sqlite. On Linux, macOS, and Windows 10 or later (tar is built in on all three):

tar -xzf DB_merged.sqlite.tar.gz

The result is an ordinary SQLite database. Open it with the sqlite3 command line, with any SQLite browser, or from Python with the standard library:

import sqlite3
con = sqlite3.connect('DB_merged.sqlite')
con.execute("SELECT COUNT(*) FROM Genes WHERE specie='H_sapiens'").fetchone()

It is also the database DOMAS reads: pass it to domas.py -dochap /path/to/DB_merged.sqlite.

 

How it was built

Gene, transcript, exon and domain annotation is integrated from Ensembl and NCBI, with protein domains from PFAM, as described in Gal-Oz et al., Nucleic Acids Research, 2021. The per-species and per-table files offered here previously were built in 2021 and have been withdrawn; this single database supersedes all of them.

 

The code for the building of DoChaP-db and the DoChaP web server is available on: https://github.com/Tal-Shay-Group/DoChaP
